# FlowerV2

**FlowerV2** 是一个以“种植与照料花朵”为主题的实体互动装置项目。本仓库用于记录装置的**物理结构、传感器与电路设计，以及 ESP32-S3 下位机程序**。上位机使用 **Max（Max/MSP）** 处理交互数据并驱动后续的数字反馈。

> **项目状态：设计与原型开发中。** 本文记录当前设计方向；传感器选型、接线、数据协议和具体实现均可能调整。

## 系统概览

观众通过种下磁性种子、移动磁性水壶、转动风车和操作旋钮与装置互动。传感器采集这些物理动作，ESP32-S3 对信号进行处理，再将交互数据发送给 Max。

**物理动作 → 传感器 → ESP32-S3（采样、滤波、校准与状态识别）→ Max（上位机交互）**

本仓库聚焦硬件与下位机。Max 补丁及视觉、声音等上层表现不属于当前仓库的主要范围。

## 互动部件

| 部件 | 物理交互 | 计划检测方式 | 目标信息 |
| --- | --- | --- | --- |
| 花盆与磁性种子 | 将内置磁铁的种子放入花盆 | 花盆底部的线性霍尔传感器 | 种子与盆底的相对距离／接近程度 |
| 磁性水壶 | 将带磁铁的水壶靠近花盆 | 线性霍尔传感器 | 水壶与花盆的相对距离／接近程度 |
| 磁编码器风车 | 手动或通过气流带动风车旋转 | 磁体与 49E 系列线性霍尔传感器构成的检测机构 | 旋转事件与转速，不要求绝对角度 |
| 旋钮 | 转动带磁性指针的旋钮 | **方案 A：** 电位器；**方案 B：** 三个 49E 系列线性霍尔传感器检测磁性指针 | 连续旋钮数值，或磁性指针最靠近的三个位置之一；无需绝对角度 |

以上均为设计目标，不代表已完成标定或功能验证。

## 硬件方案

### 主控

- **MCU：** ESP32-S3
- **职责：** 传感器采样、信号滤波、基线与阈值校准、交互状态识别，以及向上位机输出数据
- **上位机：** Max（Max/MSP）
- **通信接口及数据格式：** 待确定；初期可考虑通过 USB 串口连接 Max

### 霍尔传感器

本项目计划使用 **49E 系列的三脚线性模拟霍尔传感器**（供电、接地、模拟输出）。候选标识包括 49E、OH49E、S49E、SS49E，具体型号以实际购入器件为准。其输出是随检测到的磁场变化的模拟电压，而不是简单的开关量。

不同厂家和型号的供电范围、灵敏度、静态输出电压、极性及引脚顺序可能不同，接线前须核对实际器件的数据手册，不假定上述标识完全兼容。

**电气注意事项：** ESP32-S3 的 ADC 引脚不能直接承受 5 V 模拟信号。若使用 5 V 供电的霍尔传感器，必须先确认输出电压范围，并根据需要进行限幅或电平缩放。

### 磁性距离检测

花盆和水壶的距离检测使用磁场强度变化作为输入。霍尔输出不仅受距离影响，也受磁铁强度、朝向、传感器方向及周围磁体干扰影响。因此，**霍尔读数不直接等于绝对距离**。

后续计划通过实物标定，将原始读数转换为适合交互使用的接近程度或估计距离。多颗种子及各磁性部件之间的相互干扰也需要测试。

### 风车磁编码

计划使用霍尔传感器检测风车上磁体经过时的磁场变化。具体磁铁数量、磁极排列和传感器数量尚未确定。

风车侧的目标是识别磁性部件经过传感器时的周期性变化，以估算旋转事件与转速；**不需要绝对角度信息**。磁体布局和所需的霍尔通道数将在原型测试中确定。

### 旋钮备选方案

1. **电位器方案：** 通过 ADC 获取连续旋钮数值。
2. **三霍尔方案：** 旋钮带有**磁性指针**，三个 49E 系列线性霍尔传感器分别布置在三个位置。ESP32-S3 读取三路模拟信号，判断**磁性指针当前更靠近哪一路霍尔传感器**，输出相应的位置编号（例如 1、2、3）；不计算绝对角度。

三霍尔方案拟先记录各通道无磁体时的基线，再对三路磁场响应幅值进行标定和比较。必要时加入阈值、滞回与消抖，避免指针处于两传感器之间时频繁切换。由于输出大小也受磁极方向和传感器安装朝向影响，最终判定方法以实测为准，不能直接将未经标定的输出电压大小等同于物理距离。

最终采用电位器还是三霍尔方案尚未决定。

## 下位机软件（规划）

ESP32-S3 固件预计包含以下功能：

1. 读取各路霍尔传感器及可能采用的电位器；
2. 对原始模拟读数进行滤波和校准；
3. 将读数映射为种子、水壶、风车和旋钮的交互状态；
4. 通过与 Max 约定的接口发送数据；
5. 提供用于调试的原始数据输出和标定手段。

例如，上位机最终可能接收 `seed_proximity`、`kettle_proximity`、`windmill_speed`、`knob_position` 等逻辑数据。其中，采用三霍尔方案时，`knob_position` 表示最近霍尔传感器对应的**离散位置编号**，而不是绝对角度。**这些只是建议的字段名称，不是已经实现或确定的通信协议。**
