# FlowerV2

**FlowerV2** 是一个以“种植与照料花朵”为主题的实体互动装置项目。本仓库用于记录装置的**物理结构、传感器与电路设计，以及 ESP32-S3 下位机程序**。上位机使用 **Max（Max/MSP）** 处理交互数据并驱动后续的数字反馈。

> **项目状态：设计与原型开发中。** 本文记录当前设计方向；传感器选型、接线、数据协议和具体实现均可能调整。

## 系统概览

观众通过种下磁性种子、移动磁性水壶、转动风车和操作旋钮与装置互动。传感器采集这些物理动作，ESP32-S3 对信号进行处理，再将交互数据发送给 Max。

**物理动作 → 传感器 → ESP32-S3（采样、滤波、校准与状态识别）→ Max（上位机交互）**

本仓库聚焦硬件与下位机。Max 补丁及视觉、声音等上层表现不属于当前仓库的主要范围。

## 互动部件

| 部件 | 物理交互 | 计划检测方式 | 目标信息 |
| --- | --- | --- | --- |
| 花盆与磁性种子 | 将内置磁铁的种子放入花盆 | 花盆底部的线性霍尔传感器 | 种子与盆底的相对距离／接近程度 |
| 磁性水壶 | 将带磁铁的水壶靠近花盆 | 线性霍尔传感器 | 水壶与花盆的相对距离／接近程度 |
| 磁编码器风车 | 手动或通过气流带动风车旋转 | 磁铁与霍尔传感器构成的磁检测机构 | 旋转事件、转速；角度／方向能力待验证 |
| 旋钮 | 旋转或切换控制位置 | **方案 A：** 电位器；**方案 B：** 三个霍尔传感器配合磁体 | 连续旋钮数值，或三个离散位置（取决于最终方案） |

以上均为设计目标，不代表已完成标定或功能验证。

## 硬件方案

### 主控

- **MCU：** ESP32-S3
- **职责：** 传感器采样、信号滤波、基线与阈值校准、交互状态识别，以及向上位机输出数据
- **上位机：** Max（Max/MSP）
- **通信接口及数据格式：** 待确定；初期可考虑通过 USB 串口连接 Max

### 霍尔传感器

当前考虑的线性霍尔传感器型号包括：

- 49E
- OH49E
- S49E
- SS49E

具体型号和供电、灵敏度、输出范围、引脚定义等，需要依据实际采购器件的数据手册及实测结果确认。以上型号暂作为**候选器件**，不假定它们完全兼容。

**电气注意事项：** ESP32-S3 的 ADC 引脚不能直接承受 5 V 模拟信号。若使用 5 V 供电的霍尔传感器，必须先确认输出电压范围，并根据需要进行限幅或电平缩放。

### 磁性距离检测

花盆和水壶的距离检测使用磁场强度变化作为输入。霍尔输出不仅受距离影响，也受磁铁强度、朝向、传感器方向及周围磁体干扰影响。因此，**霍尔读数不直接等于绝对距离**。

后续计划通过实物标定，将原始读数转换为适合交互使用的接近程度或估计距离。多颗种子及各磁性部件之间的相互干扰也需要测试。

### 风车磁编码

计划使用霍尔传感器检测风车上磁体经过时的磁场变化。具体磁铁数量、磁极排列和传感器数量尚未确定。

单个线性霍尔传感器可以用于检测周期性变化并估算转速，但**不能仅凭周期信号保证获得唯一的绝对角度或旋转方向**。若后续需要可靠的角度／方向信息，将进一步评估磁体布局、增加传感器或更换编码器方案。

### 旋钮备选方案

1. **电位器方案：** 通过 ADC 获取连续位置值，结构和程序较简单。
2. **三霍尔方案：** 通过磁体与三个霍尔传感器的相对位置区分三个指定档位；需要验证磁体布局、阈值和抗干扰能力。

最终采用哪一种方案尚未决定。

## 下位机软件（规划）

ESP32-S3 固件预计包含以下功能：

1. 读取各路霍尔传感器及可能采用的电位器；
2. 对原始模拟读数进行滤波和校准；
3. 将读数映射为种子、水壶、风车和旋钮的交互状态；
4. 通过与 Max 约定的接口发送数据；
5. 提供用于调试的原始数据输出和标定手段。

例如，上位机最终可能接收 `seed_proximity`、`kettle_proximity`、`windmill_speed`、`knob_position` 等逻辑数据。**这些只是建议的字段名称，不是已经实现或确定的通信协议。**
