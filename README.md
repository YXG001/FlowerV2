# FlowerV2

**FlowerV2** 是一个以“种植与照料花朵”为主题的实体互动装置项目。本仓库用于记录装置的**物理结构、传感器与电路设计，以及 ESP32-S3 下位机程序**。上位机使用 **Max（Max/MSP）** 处理交互数据并驱动后续的数字反馈。

> **项目状态：首版 ESP32-S3 固件已提交，尚待本地编译、烧录和实物标定。**

## 系统概览

观众通过种下磁性种子、移动磁性水壶、转动风车和操作旋钮与装置互动。传感器采集这些物理动作，ESP32-S3 对信号进行处理，再将交互数据发送给 Max。

**物理动作 → 传感器 → ESP32-S3（采样、滤波、校准与状态识别）→ Max（上位机交互）**

本仓库聚焦硬件与下位机。Max 补丁及视觉、声音等上层表现不属于当前仓库的主要范围。

## 互动部件

| 部件 | 物理交互 | 计划检测方式 | 目标信息 |
| --- | --- | --- | --- |
| 花盆与磁性种子 | 将内置磁铁的种子放入花盆 | 花盆底部的 49E 系列线性霍尔传感器 | **`seed_state`：0/1 开关量**，同时发送连续传感器读数 `seed_value` |
| 磁性水壶 | 将带磁铁的水壶靠近花盆 | 49E 系列线性霍尔传感器 | **`kettle_state`：0/1 开关量**，同时发送连续传感器读数 `kettle_value` |
| 磁编码器风车 | 手动或通过气流带动风车旋转 | 磁体与 49E 系列线性霍尔传感器构成的检测机构 | **`windmill_state`：0/1 转动状态**，以及 `windmill_rpm`；不要求绝对角度 |
| 旋钮 | 转动电位器旋钮 | **电位器 + ESP32-S3 ADC** | 将旋钮位置量化为三个档位 **0、1、2**，并额外输出原始 ADC 值 `knob_raw`（不等同于角度） |

以上均为设计目标，不代表已完成标定或功能验证。

## 硬件方案

### 主控

- **MCU：** ESP32-S3
- **职责：** 传感器采样、信号滤波、基线与阈值校准、交互状态识别，以及向上位机输出数据
- **上位机：** Max（Max/MSP）
- **通信接口及数据格式：** 已参考 [FlowerV1](https://github.com/YXG001/FlowerV1) 编写 USB 串口、空格分隔 ASCII 数字与换行分帧的八字段协议（原七字段之后增加 `knob_raw`）

### 霍尔传感器

本项目计划使用 **49E 系列的三脚线性模拟霍尔传感器**（供电、接地、模拟输出）。候选标识包括 49E、OH49E、S49E、SS49E，具体型号以实际购入器件为准。其输出是随检测到的磁场变化的模拟电压，而不是简单的开关量。

不同厂家和型号的供电范围、灵敏度、静态输出电压、极性及引脚顺序可能不同，接线前须核对实际器件的数据手册，不假定上述标识完全兼容。

**电气注意事项：** ESP32-S3 的 ADC 引脚不能直接承受 5 V 模拟信号。若使用 5 V 供电的霍尔传感器，必须先确认输出电压范围，并根据需要进行限幅或电平缩放。

### 种子与水壶接近检测（0/1 输出）

花盆底部和水壶检测位置使用 49E 系列线性霍尔传感器采集磁场变化。**交互判断使用二值状态 `seed_state` / `kettle_state`，同时发送对应的连续读数 `seed_value` / `kettle_value`，供 Max 观察和后续调整。** 连续读数暂不解释为物理距离：

| 字段（暂定） | 0 | 1 |
| --- | --- | --- |
| `seed_state` | 未检测到种子接近／有效放置 | 检测到种子接近／有效放置 |
| `kettle_state` | 未检测到水壶接近 | 检测到水壶接近 |

首版固件采用 FlowerV1 的相对基线百分比公式 `(filtered - zero) / zero * 100` 计算 `seed_value`、`kettle_value`（有符号百分比，不是物理距离）。通过触发／释放双阈值生成对应的 0/1 状态；默认 5% 触发、3% 释放，需实测调整。建议使用带**触发阈值与释放阈值（滞回）**的状态机，防止磁铁在临界位置附近造成 0/1 抖动。

霍尔磁场响应与磁体距离、强度、极性、安装朝向及其他磁体干扰都有关，因此该状态表示**接近检测结果**，而不是某个已知厘米数的绝对距离。多个种子、风车磁体和磁性水壶之间的串扰需要实测。

启动校准应在**种子未放置、水壶未靠近**的已知空闲状态下进行。若在有磁体存在时重新归零，可能把当前磁场错误地当成背景基线。

### 风车磁编码

计划使用霍尔传感器检测风车上磁体经过时的磁场变化。具体磁铁数量、磁极排列和传感器数量尚未确定。

风车不需要绝对角度。当前采用目标约 1 kHz 的 ADC 采样、三点中值滤波、快速滤波、动态基线、连续两次采样确认和滞回峰值检测。`windmill_rpm` 根据脉冲间隔计算；`windmill_state` 为停止 0／转动 1，**在两次有效脉冲建立周期后才确认旋转**，停止超时后 RPM 归零。目前安装 3 颗磁铁，按照每颗磁铁经过时产生一个有效脉冲设置为 **3 脉冲/转**。必须检查实际磁极方向和阈值，确认每转确实检测到三次有效正向磁峰。

### 旋钮：电位器（已选定）

旋钮使用**电位器**，不再采用三个霍尔传感器检测磁性指针的备选方案。电位器两端接合适的供电与 GND，滑动端连接 ESP32-S3 的 ADC 输入；保证滑动端电压不超过 MCU ADC 的允许范围。

ESP32-S3 读取连续 ADC 数值，在固件中转换成三个离散档位，**向 Max 发送档位整数 `0`、`1`、`2`，同时额外发送原始 ADC 读数 `knob_raw`（0–4095）**。初始方案可根据实测有效行程将其划分为三段；边界增加适当滞回，防止旋钮停留在两档临界位置时抖动。具体阈值以及是否使用机械定位式电位器，待实际选型后确定。

## 首版 ESP32-S3 固件

本仓库使用 **PlatformIO + Arduino（ESP32-S3）**，不是原生 ESP-IDF 项目。源码实现了 FlowerV1 风格的 ADC 校准、IIR 滤波、`c/C` 重新校准、八字段串口输出（前七字段顺序不变），以及风车转速和旋钮分档。**目前未进行 PlatformIO 编译及实物验证。**

`include/`、`lib/`、`test/` 中的说明文件用于在 Git 中保留目录；**它们不是编译所必需的**。当前实际固件仍在 `src/main.cpp`，不引入虚构的组件或空实现。

本项目不需要 ESP-IDF 专用的 `CMakeLists.txt`、`sdkconfig` 或 `main/`。PlatformIO 会在首次构建时自动生成 `.pio/`，这个目录是构建缓存，通常不应提交 GitHub。

在 VS Code 中打开包含 `platformio.ini` 的 **FlowerV2 仓库根目录**，而不是只打开 `src/`。

### 配置区：只保留经常需要调节的项目

`src/main.cpp` 的 **USER CONFIGURATION** 位于文件开头，只保留四组与接线、标定直接相关的选项：

1. **四路 ADC 引脚：** `PIN_SEED`、`PIN_KETTLE`、`PIN_WINDMILL`、`PIN_KNOB`。
2. **种子与水壶的开关阈值：** 分别设置 ON / OFF 的相对基线百分比。
3. **风车磁编码器：** 有效脉冲数、磁峰极性、触发／释放阈值，以及最短停转超时。
4. **旋钮电位器：** ADC 有效上下限和三档切换滞回。

串口波特率、采样周期、IIR 滤波系数、校准采样次数、LED 亮度和其他风车内部计时系数，都放在紧接着的 **Internal defaults** 区域。**这些默认值没有改变，通常无需修改。** 后续需要高级优化时仍能在同一源码中找到。

源码文件头注释提供 ESP32-S3 的 ADC 引脚选择说明。推荐优先使用 GPIO1、GPIO2、GPIO4～GPIO10（ADC1）。GPIO3 为启动配置引脚，不建议使用；GPIO11～20 对应 ADC2，GPIO19/20 还关联原生 USB。是否实际可用要根据开发板接线和其他功能判断。

编译期检查会拒绝不支持 ADC 的 GPIO 和重复分配的 ADC 引脚。

### 默认接线（在 main.cpp 顶部修改）

| 设备 | ESP32-S3 | ADC |
| --- | --- | --- |
| 种子霍尔 OUT | GPIO4 | ADC1_CH3 |
| 水壶霍尔 OUT | GPIO5 | ADC1_CH4 |
| 风车霍尔 OUT | GPIO6 | ADC1_CH5 |
| 电位器滑动端 | GPIO7 | ADC1_CH6 |

所有传感器必须共地。电位器可使用 3.3 V 与 GND 供电；49E 系列具体引脚及供电范围请核对实际器件手册。**ESP32-S3 ADC 不能直接承受 5 V 模拟输出**，若霍尔需要 5 V 供电，应采用合适的模拟分压／限幅，并注意 ADC 可用测量电压范围。

### 编译和串口

使用 VS Code + PlatformIO，目标板延续 FlowerV1 的 `rymcu-esp32-s3-devkitc-1`。

```bash
pio run
pio run -t upload
pio device monitor -b 115200
```

固件每 50 ms（约 20 Hz）通过 USB 串口发送一行，共 **8 个**空格分隔的数字，行尾为换行。前 7 个字段顺序不变；第 8 个字段 `knob_raw` 是电位器未经滤波的 ADC 读数：

```text
seed_state kettle_state windmill_state knob_value seed_value kettle_value windmill_rpm knob_raw
```

示例数据（仅演示格式，非实测）：

```text
0 0 0 0 0.00 0.00 0.0 280
1 0 1 1 5.85 -0.31 45.2 1830
1 1 1 2 8.21 7.68 120.5 3670
0 1 0 2 0.60 6.92 0.0 3610
```

| 字段 | 定义 |
| --- | --- |
| `seed_state` / `kettle_state` | 二值 `0/1`，对应磁体接近状态 |
| `windmill_state` | 二值 `0/1`，风车停止／检测到转动 |
| `knob_value` | 离散 `0/1/2`，电位器三个档位 |
| `seed_value` / `kettle_value` | 相对开机零点的有符号百分比，不是厘米距离 |
| `windmill_rpm` | 非负转速 RPM，停止超时归零 |
| `knob_raw` | 最新一次电位器 ADC 原始采样值（12-bit，0–4095），用于观察与标定 |

Max 中将原来的 `unpack i i i i f f f` 改为 `unpack i i i i f f f i`，第八个出口接 `number` 可查看原始 ADC。既有前七个出口的含义不变。电位器档位依据滤波后的 ADC 计算，因此位于边界或旋转过程中，`knob_raw` 与当前档位不一定瞬时严格对应。

### 风车转速与停转响应（2026-10-31 调整）

针对三磁铁风车和此前静止时的异常脉冲记录，现使用：

| 内部参数 | 当前值 | 用途 |
| --- | ---: | --- |
| `RPM_FILTER_ALPHA` | 0.70 | 稳速或减速时的脉冲周期 IIR；兼顾波动抑制 |
| `RPM_ACCEL_ALPHA` | 0.95 | 突然加速时优先跟随缩短的实际脉冲间隔 |
| `WINDMILL_STOP_PERIOD_FACTOR` | 1.8 | 距上一次脉冲超过约 1.8 倍估计脉冲周期时停止 |
| `WINDMILL_MIN_TIMEOUT_US` | 400000（0.4 s） | 高速停转最短判定延迟（用户配置区） |
| `WINDMILL_CONFIRM_SAMPLES` | 2 | 滤波后响应连续两次高速采样超过 ON 阈值，才接受脉冲 |
| `WINDMILL_INITIAL_TIMEOUT_US` | 8000000（8 s） | 第一次有效脉冲之后、尚未得到有效周期时的超时（保留低速启动余量） |
| `WINDMILL_MAX_TIMEOUT_US` | 20000000（20 s） | 自适应停转超时上限 |

风车 ADC 使用**三采样点中值滤波**，抑制孤立 ADC 瞬态尖峰。为改善突然手拨风车时窄磁峰漏检，目标采样间隔由 2 ms 改为 **1 ms**（仅为目标，实际受主循环执行时间影响），快速滤波系数由 0.35 增至 **0.50**。滤波与脉冲确认可能导致非常狭窄的实际磁峰漏计，尤其在高速和弱磁场情况下，需要实测确认。

当已有可信脉冲周期、但下一颗磁铁尚未到来时，程序在经过原预计周期后，会根据已等待时间逐渐限制输出 RPM，避免旧速度保持不变直到突然归零。只有在第二次有效脉冲后才输出 `windmill_state = 1`，普通八字段协议保持不变。

**预计的停转延迟（恒速后突然停止、无误脉冲）：** 30 RPM 约 1.2 秒，60 RPM 约 0.6 秒，120 RPM 约 0.4 秒。约 50 ms 的串口更新周期带来额外延迟。极低转速仍然需要较长的超时，例如 5 RPM、每转 3 个脉冲时，相邻脉冲相隔约 4 秒，停转判定不能直接缩短到 0.4 秒。

**诊断注意：** 以前的静止日志显示持续假脉冲（偶发 ADC 原始读数有大幅异常）；本次增加的中值滤波和短时确认只是在软件层面降低误计数，不能代替对传感器供电、接地、线束以及 ADC 电气噪声的排查。若风车停转后仍持续出现 RPM，先使用下方 `d` 模式观察 `pulse_count`。检测阈值同步用户近期本地代码的 `100/60`，需要根据实测真实磁峰重新标定。

**突然旋转的物理限制：** 三磁铁方案在从静止开始后，必须先收到两次真实磁脉冲才能计算 RPM。第一颗脉冲只能确认一次磁场经过，不能单独确定转速；一旦第二颗被检测到，就直接以首次测到的脉冲间隔初始化转速。极短的拨动如果只经过一颗磁铁，输出 RPM 仍为 0，这不能单靠提高滤波系数解决。若磁铁排列和大小允许，也可增加磁铁数改善初始反馈速度。

**快速加速算法：** 与上一周期相比，当最新脉冲间隔缩短（加速）时，使用 `RPM_ACCEL_ALPHA=0.95`，减少此前的平滑延迟；在周期变长时继续使用 `RPM_FILTER_ALPHA=0.70`，使减速较稳定。停转超时参数保持 1.8 倍周期、最低 0.4 秒。为保留之前静止抗干扰的效果，三点中值滤波和两次连续采样确认保持启用。需要继续用 `d` 模式分别检查静止和突然拨动的 `pulse_count` 与 `response_max`。

### 风车 ADC 调试模式（排查静止时误计数）

固件增加了**可选调试命令 `d` / `D`**。在串口监视器输入字母 `d`（ASCII 100）后，下一帧起从普通的八字段格式切换为 20 Hz 的风车诊断行。再次发送 `d`，恢复八字段 Max/MSP 数据流。此功能默认关闭，**不会更改霍尔检测阈值或 RPM 算法**。

示例格式（数值仅为格式演示）：

```text
W 2032 2024 2058 2035.1 2039.7 -4.6 -14.0 33.2 2 1 150.0
```

`W` 后各字段按顺序为：

| 字段 | 含义 |
| --- | --- |
| `raw` | 最新的风车 ADC 原始读数 |
| `raw_min`, `raw_max` | 上一个输出周期内全部高速采样的最小、最大 ADC 值 |
| `filtered` | 快速滤波后的 ADC 数值 |
| `baseline` | 慢速动态基线 |
| `response` | 最新的有符号磁场变化值（已乘 `WINDMILL_PEAK_POLARITY`） |
| `response_min`, `response_max` | 输出周期内磁场响应的极值 |
| `pulse_count` | 本次开启调试以来，通过阈值及防抖检查的累计磁脉冲数 |
| `windmill_state`, `windmill_rpm` | 当前状态和 RPM |

诊断流程：**固定风车不动**，开启 `d` 记录 5–10 秒；然后手动缓慢转动，记录相同字段。重点比较静止时 `response_max` 与转动经过磁铁时的 `response_max`，并检查 `pulse_count` 在静止时是否增加。若静止时仍有脉冲，说明当前阈值、噪声或磁场干扰引发误计数。诊断模式会暂停正常 Max 八字段输出，退出后才恢复。

在 PlatformIO 串口监视器或串口终端中使用时，关闭其他占用同一串口的应用。重新烧录后再测试；以前仅有七字段输出的固件不支持该命令。

### FlowerV1 风格的自动校准及滤波

- 开机后先等待约 1 秒，然后按 10 ms 间隔采集 200 次磁场数据计算各通道基线；约 3 秒内完成。校准期间**暂停数据帧输出**。
- 将 ASCII 字符 `c` 或 `C` 发给下位机，即可重新执行校准。
- **校准前必须移开种子和水壶磁铁，并停止风车。** 电位器不需要磁场零点校准。
- 种子／水壶／旋钮约 50 Hz 采样，使用 V1 相同的一阶 IIR 系数 `0.20`；连续霍尔输出为相对百分比。
- 风车目标约 500 Hz 采样，利用快滤波、慢速基线、磁峰阈值和脉冲周期估算转速。
- 若板卡提供 `RGB_BUILTIN`，蓝灯闪烁表示校准，绿灯常亮表示就绪，红灯表示校准数据异常。

| `PIN_SEED / PIN_KETTLE / PIN_WINDMILL / PIN_KNOB` | 4 / 5 / 6 / 7 | 实际接线不同 |
| `SEED_ON_PERCENT / SEED_OFF_PERCENT` | 5 / 3 | 种子触发距离或误报不合适 |
| `KETTLE_ON_PERCENT / KETTLE_OFF_PERCENT` | 5 / 3 | 水壶触发距离或误报不合适 |
| `WINDMILL_PULSES_PER_REV` | 3 | 每转实际可计数的磁峰数量不同 |
| `WINDMILL_PEAK_POLARITY` | +1 | 磁峰方向与默认相反 |
| `WINDMILL_ON_COUNTS / WINDMILL_OFF_COUNTS` | 100 / 60 | 保留实物测试阈值，增大检测阈值可抑制假脉冲，但会漏掉弱磁峰 |
| `WINDMILL_MIN_TIMEOUT_US` | 400000 | 需要调整停转反馈的最低延迟 |
| `KNOB_ADC_MIN / KNOB_ADC_MAX` | 0 / 4095 | 实际电位器不能覆盖默认量程 |
| `KNOB_HYSTERESIS_COUNTS` | 50 | 旋钮在档位边界抖动 |

风车磁峰必须独立可分辨；磁铁过密导致磁场叠加、极性不匹配或阈值不合适都可能漏计和误计。需要先手动旋转一圈确认实际每圈脉冲数，之后再调整相关参数。
